# 学生信息管理系统
## 项目简介

这是一个使用 Python 编写的学生信息管理系统，
主要用于练习 Python 面向对象、函数、列表和模块的综合使用。
## 项目功能

- 查看所有学生信息
- 查看学生成绩等级
- 判断学生是否及格
- 统计学生总分
- 计算平均分
- 查找最高分学生
- 查找最低分学生
- 统计及格人数
- 统计优秀人数
- 使用菜单进行程序操作
