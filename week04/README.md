# 学生成绩管理系统

## 项目简介

这是第四周 Python OOP + 模块学习完成的小型项目。

项目主要用于练习：
- Python 面向对象
- 类与对象
- 方法
- 参数
- return
- 模块
- 多文件项目

## 项目结构

day6/
├── student.py
├── calculate.py
├── main.py
└── README.md

## 功能

### Student
- 创建学生
- 查看学生信息
- 修改成绩
- 判断是否及格
- 获取成绩等级

### Calculate
- 计算平均成绩
- 计算总成绩

## 运行方法

运行 main.py 即可。

## 学习内容

本项目主要使用 Python 基础语法、面向对象和模块化编程完成。
